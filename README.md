## Community Health Files

https://docs.github.com/en/enterprise-cloud@latest/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file#about-default-community-health-files

This repository features different issue templates and a pull request template.

When creating a new issue the template chooser is presented and a template has to be chosen for the new issue. Nevertheless, is still possible to start from a blank issue.

The templates are rather extensive and shall help its user to not forget certain aspects of an issue or a pull request. Sections that are not applicable can be freely deleted.

- [Action plan](.github/ISSUE_TEMPLATE/action_plan.md)
Create a list of items to be done on this project.
  - `Type: Task` A specific piece of work.
  - `Type: DevOps` A job that should be automated in an appropriate manner.

- [Architecture Decision Record](.github/ISSUE_TEMPLATE/architecture_decision_record.md)
Capture an important conclusion made along with its context and consequences.
  - `Type: Requirement` A condition or capability that must be met under certain conditions.

- [Bug report](.github/ISSUE_TEMPLATE/bug_report.md)
Report a problem with this project.
  - `Type: Bug` An unexpected behavior or problem.
  - `Type: Security` A vulnerability in the code base, the supply chain, or the configuration.

- [Feature request](.github/ISSUE_TEMPLATE/feature_request.md)
Suggest an idea for this project.
  - `Type: Feature` A request, idea, or needed functionality.

- [Pull Request](.github/pull_request_template.md)
Proposal for a change to the codebase.
    - `Type: Pull Request` A request to merge code changes into the main branch.

## Markdown Alert Syntax

https://docs.github.com/en/enterprise-cloud@latest/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax#alerts

> [!NOTE]
> Useful information that users should know, even when skimming content.

> [!TIP]
> Helpful advice for doing things better or more easily.

> [!IMPORTANT]
> Key information users need to know to achieve their goal.

> [!WARNING]
> Urgent info that needs immediate user attention to avoid problems.

> [!CAUTION]
> Advises about risks or negative outcomes of certain actions.
